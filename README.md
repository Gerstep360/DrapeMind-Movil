# drapemind_mobile

## Probador virtual

El modo `2d-overlay` abre la cámara frontal real y superpone el asset validado por el backend,
con escala derivada de talla y medidas. Es AR 2D funcional; no se presenta como seguimiento
corporal 3D. La segmentación y el anclaje automático por articulaciones requieren integrar
posteriormente un modelo de pose en el dispositivo.

A new Flutter project.
